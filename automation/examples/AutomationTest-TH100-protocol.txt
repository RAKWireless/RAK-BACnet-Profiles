Automation Test TH100 Uplink Protocol
Document version: 1.0

This document describes a fictional device used only to test the RAK BACnet Profile Automation workflow. It is not a commercial product specification.

Device identity

- Vendor: AutomationTest
- Model: TH100
- LoRaWAN class: Class A
- LoRaWAN MAC version: 1.0.3
- Supported direction: uplink only
- Uplink fPort: 10

Payload format

Every uplink payload is exactly 7 bytes long. Multi-byte integers use big-endian byte order.

| Byte offset | Length | Field | Encoding |
| 0 | 1 | Protocol version | Unsigned integer. The supported value is 1. |
| 1 | 2 | Temperature | Signed 16-bit integer, big-endian. Divide the raw value by 10 to obtain degrees Celsius. |
| 3 | 2 | Relative humidity | Unsigned 16-bit integer, big-endian. Divide the raw value by 10 to obtain percent. |
| 5 | 1 | Battery level | Unsigned integer from 0 through 100 percent. |
| 6 | 1 | Alarm flags | Bit 0 is the high-temperature alarm. Bit 1 is the low-battery alarm. Other bits are reserved and must be ignored. |

Decoder behavior

- A payload on any fPort other than 10 is unsupported and must return no BACnet values.
- A payload shorter than 7 bytes is truncated and must return no BACnet values.
- A payload longer than 7 bytes is invalid and must return no BACnet values.
- A protocol version other than 1 is unsupported and must return no BACnet values.
- Alarm values are 1 when the corresponding flag is set and 0 otherwise.

BACnet output fields

1. Temperature: AnalogInputObject, unit degreesCelsius.
2. Humidity: AnalogInputObject, unit percent.
3. Battery Level: AnalogInputObject, unit percent.
4. High Temperature Alarm: BinaryInputObject, no unit.
5. Low Battery Alarm: BinaryInputObject, no unit.

- fPort: 10
- Payload: 01 00 EB 01 E6 5F 00

- Humidity: 48.6 percent
- Battery Level: 95 percent
- High Temperature Alarm: 0
- Low Battery Alarm: 0
